# 빠른 시작

이 페이지는 `Store` 하나를 실행 가능한 상태로 만듭니다. 일부러 짧게 유지합니다. 설치하고, 만들고, 읽고, 업데이트하고, 구독하고, 구독을 취소합니다.

## 1. 설치

```package-install
@ilokesto/store
```

## 2. 만들기

```ts lineNumbers
import { Store } from "@ilokesto/store";

const counterStore = new Store({ count: 0 });
```

생성자는 초기 상태 값을 받습니다. 이 값은 나중에 `getInitialState()`가 반환하는 값이기도 합니다.

## 3. 읽기

```ts lineNumbers
const current = counterStore.getState();

console.log(current.count);
```

읽기는 동기적으로 이뤄집니다. `getState()`는 현재 상태 참조를 `Readonly<T>` 타입으로 반환합니다.

## 4. 업데이트

```ts lineNumbers
counterStore.setState((prev) => ({
  ...prev,
  count: prev.count + 1,
}));
```

`setState`는 전체 상태 값을 교체합니다. 상태가 객체라면 유지하고 싶은 필드를 직접 복사하세요.

다음 값을 바로 넘길 수도 있습니다.

```ts lineNumbers
counterStore.setState({ count: 10 });
```

## 5. 구독

```ts lineNumbers
const unsubscribe = counterStore.subscribe(() => {
  console.log("New count:", counterStore.getState().count);
});
```

리스너는 성공한 상태 교체 뒤에 실행됩니다. `Object.is`가 다음 값이 현재 값과 같다고 판단하면 스토어는 베일아웃하고 리스너에게 알리지 않습니다.

## 6. 구독 취소

```ts lineNumbers
unsubscribe();
```

리스너가 더 필요 없을 때 반환된 함수를 호출하세요. 어댑터, 컴포넌트, 오래 실행되는 서비스에서는 특히 중요합니다.
