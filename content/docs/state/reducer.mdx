# Reducer

For complex state transitions, `@ilokesto/state` supports a reducer-based mode similar to React's `useReducer` or Redux.

## Defining a Reducer

A reducer is a pure function that takes the current state and an action, and returns the next state.

```ts lineNumbers
import { create } from '@ilokesto/state/react';

type State = { count: number };
type Action = { type: 'increment' } | { type: 'decrement' } | { type: 'set'; value: number };

const counterReducer = (state: State, action: Action): State => {
  switch (action.type) {
    case 'increment': return { count: state.count + 1 };
    case 'decrement': return { count: state.count - 1 };
    case 'set': return { count: action.value };
    default: return state;
  }
};

const useCounter = create(counterReducer, { count: 0 });
```

## Dispatching Actions

In reducer mode, the hook returns a `dispatch` function instead of `setState`.

```tsx lineNumbers
function Counter() {
  const [count, dispatch] = useCounter(state => state.count);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => dispatch({ type: 'increment' })}>Increment</button>
      <button onClick={() => dispatch({ type: 'decrement' })}>Decrement</button>
    </div>
  );
}
```

## Global Dispatch

Use the `writeOnly` accessor when code outside React needs to dispatch an action.

```ts lineNumbers
export const incrementCount = () => {
  const dispatch = useCounter.writeOnly();
  dispatch({ type: 'increment' });
};
```

## When to use reducer mode

- Use reducer mode when one action needs to update several fields together.
- Use it when each transition needs validation or branching before the next state is returned.
- Use it when named actions make debugging clearer with `logger` or `devtools` middleware.
- Use it when existing `useReducer` logic should move into a shared store with minimal shape changes.

## Reducer mode behavior

Reducers must always return the **full** state object. Partial state updates are not supported in reducer mode.

Reducer-based stores support all `@ilokesto/state` middleware.
