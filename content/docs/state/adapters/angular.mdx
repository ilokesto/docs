# Angular

Import Angular adapter APIs from `@ilokesto/state/angular`.

```ts lineNumbers
import { Component, DestroyRef, inject } from '@angular/core';
import { create } from '@ilokesto/state/angular';

type CounterState = { count: number };

const counter = create<CounterState>({ count: 0 });

@Component({
  selector: 'app-counter',
  standalone: true,
  template: '<button (click)="increment()">{{ count() }}</button>',
})
export class CounterComponent {
  private readonly destroyRef = inject(DestroyRef);
  readonly count = counter((state) => state.count, { destroyRef: this.destroyRef }).state;

  increment() {
    counter.writeOnly()((prev) => ({ ...prev, count: prev.count + 1 }));
  }
}
```

## Return shape

The Angular adapter returns a function that produces signals:

- state mode: `{ state: Signal<S>, setState, subscribe }`
- reducer mode: `{ state: Signal<S>, dispatch, subscribe }`

## Lifecycle rule

If you create an Angular signal outside an active injection context, pass `{ destroyRef }` explicitly. The adapter uses that scope to clean up the store subscription.
