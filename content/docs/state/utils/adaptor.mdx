# `adaptor`

`adaptor` turns an Immer draft recipe into a pure updater for object state. Write the mutation against `draft`; the returned function produces the next immutable state.

```ts lineNumbers
import { adaptor } from '@ilokesto/state/utils';

type State = { user: { profile: { name: string } } };

const renameProfile = adaptor<State>((draft) => {
  draft.user.profile.name = 'New Name';
});

useStore.writeOnly()(renameProfile);
```

## Behavior

- `adaptor` accepts object state shapes.
- The recipe receives an Immer draft, so nested assignments are valid inside the recipe.
- The returned updater is a pure function that can be passed to `writeOnly()`.
- `immer` is an optional peer dependency. Install it before using `adaptor`.

## Installation

```package-install
immer
```
