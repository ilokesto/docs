# Store

`@ilokesto/store` is the small state container at the center of the Store docs. It holds one state value, replaces that value through `setState`, and notifies listeners when a replacement succeeds.

Use this package when you need a plain TypeScript state contract that does not depend on React, Vue, Svelte, Angular, or any other framework.

## Package boundary

The package exports `Store<T>` from `@ilokesto/store`.

It covers:

- storing one state value,
- reading the current and initial state,
- replacing state with a value or updater function,
- subscribing to successful state changes,
- adding source backed middleware with the current public method names.

It does not provide framework hooks, selectors, reducers, persistence, data fetching, devtools, or async scheduling. Those belong in adapters or higher level packages.

## Install

```package-install
@ilokesto/store
```

## Small example

```ts
import { Store } from "@ilokesto/store";

const counterStore = new Store({ count: 0 });

const unsubscribe = counterStore.subscribe(() => {
  console.log(counterStore.getState());
});

counterStore.setState((prev) => ({ ...prev, count: prev.count + 1 }));

unsubscribe();
```

This example is intentionally plain. It shows the whole package shape: create one store, read a snapshot, replace state, listen for changes, and remove the listener when it is no longer needed.
