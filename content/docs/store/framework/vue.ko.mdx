# Vue

Vue 3의 반응형 시스템은 ref와 computed 값을 중심으로 구축되어 있습니다. `shallowRef`는 스토어 스냅샷을 단일 반응형 참조로 미러링하고, `watchEffect`(또는 `watch`)가 동기화를 담당합니다. 정리는 `onUnmounted`가 처리합니다.

## 어댑터

최소 어댑터는 `shallowRef`를 생성하고, 스토어를 구독하고, readonly 참조를 반환합니다.

```ts lineNumbers
import { shallowRef, readonly, onUnmounted } from "vue";
import { Store } from "@ilokesto/store";

export function useStore<T>(store: Store<T>) {
  const state = shallowRef(store.getState());

  const unsubscribe = store.subscribe(() => {
    state.value = store.getState();
  });

  onUnmounted(unsubscribe);

  return readonly(state);
}
```

`ref` 대신 `shallowRef`를 사용하는 이유는, 스토어 상태가 이미 외부에서 관리되는 스냅샷 값이기 때문입니다. 깊은 반응성은 필요하지 않으며 큰 상태 트리에서는 오버헤드가 발생합니다. `readonly`는 템플릿 코드에서의 우발적인 직접 변경을 방지합니다.

이 컴포저블을 컴포넌트 레벨에서 사용하면 `onUnmounted`가 올바른 라이프사이클 스코프를 갖습니다. setup 컨텍스트 외부에서 호출하면 `onUnmounted`가 활성 컴포넌트 인스턴스를 필요로 하기 때문에 오류가 발생합니다.

## 셀렉터 패턴

`computed`로 파생된 슬라이스를 만드세요. computed 값은 `shallowRef`가 변경될 때만 업데이트되고, Vue의 의존성 추적은 읽는 필드가 변경될 때만 하위 effects가 다시 실행되도록 보장합니다.

```ts lineNumbers
import { shallowRef, computed, readonly, onUnmounted } from "vue";
import { Store } from "@ilokesto/store";

export function useSelector<T, U>(
  store: Store<T>,
  selector: (state: T) => U,
) {
  const state = shallowRef(store.getState());

  const unsubscribe = store.subscribe(() => {
    state.value = store.getState();
  });

  onUnmounted(unsubscribe);

  return computed(() => selector(state.value));
}
```

```ts lineNumbers
// count 필드가 변경될 때만 재계산됩니다.
const count = useSelector(counterStore, (s) => s.count);
```

`computed`는 지연 평가되고 캐시됩니다. 셀렉터는 컴포넌트가 값을 읽고 이전 읽기 이후 상위 `shallowRef`가 변경된 경우에만 실행됩니다.

## 여러 스토어

단일 setup 함수에서 여러 컴포저블을 조합하세요. 각 구독은 독립적으로 스코핑됩니다.

```vue lineNumbers
<script setup lang="ts">
import { useSelector } from "./composables/useSelector";
import { authStore } from "./stores/auth";
import { themeStore } from "./stores/theme";

const user = useSelector(authStore, (s) => s.user);
const theme = useSelector(themeStore, (s) => s);
</script>

<template>
  <header :data-theme="theme">
    <span v-if="user">{{ user.name }}</span>
    <span v-else>로그인</span>
  </header>
</template>
```

`themeStore`가 변경되어도 `authStore` 구독은 무효화되지 않습니다.

## TypeScript

컴포저블은 완전히 제네릭합니다. Vue의 `ComputedRef<U>`는 셀렉터에서 추론된 타입을 유지합니다.

```ts lineNumbers
import { Store } from "@ilokesto/store";

type AuthState = {
  user: { id: string; name: string } | null;
  status: "anonymous" | "signed-in";
};

export const authStore = new Store<AuthState>({
  user: null,
  status: "anonymous",
});

// ComputedRef<{ id: string; name: string } | null>
const user = useSelector(authStore, (s) => s.user);

// ComputedRef<"anonymous" | "signed-in">
const status = useSelector(authStore, (s) => s.status);
```

컴포넌트 코드를 스토어 임포트로부터 자유롭게 하려면 스토어별 컴포저블로 감싸세요:

```ts lineNumbers
// composables/useAuth.ts
export function useAuthUser() {
  return useSelector(authStore, (s) => s.user);
}

export function useAuthStatus() {
  return useSelector(authStore, (s) => s.status);
}
```

## 테스트

`@vue/test-utils`의 `mount`와 최소 테스트 컴포넌트로 컴포저블을 테스트하거나, `effectScope`를 사용해 전체 컴포넌트 없이 컴포저블을 실행하세요.

```ts lineNumbers
import { mount } from "@vue/test-utils";
import { defineComponent, nextTick } from "vue";
import { expect, test } from "vitest";
import { Store } from "@ilokesto/store";
import { useStore } from "./composables/useStore";

test("스토어 상태를 템플릿에 노출한다", async () => {
  const store = new Store({ count: 0 });

  const TestComponent = defineComponent({
    setup() {
      return { state: useStore(store) };
    },
    template: `<span>{{ state.count }}</span>`,
  });

  const wrapper = mount(TestComponent);

  expect(wrapper.text()).toBe("0");

  store.setState({ count: 3 });
  await nextTick();

  expect(wrapper.text()).toBe("3");
});

test("언마운트 시 구독을 해제한다", () => {
  const store = new Store({ count: 0 });
  let calls = 0;

  const TestComponent = defineComponent({
    setup() {
      return { state: useStore(store) };
    },
    template: `<span></span>`,
  });

  const wrapper = mount(TestComponent);
  wrapper.unmount();

  store.setState({ count: 1 });

  // 언마운트 후 listener가 실행되지 않아야 합니다.
  expect(calls).toBe(0);
});
```

스토어 업데이트 후 DOM 내용을 검증하기 전에 항상 `await nextTick()`을 사용하세요. Vue는 DOM 업데이트를 비동기적으로 배치하기 때문입니다.
