# Svelte

Import Svelte adapter APIs from `@ilokesto/state/svelte`.

```ts lineNumbers
import { create } from '@ilokesto/state/svelte';

type CounterState = { count: number };

export const counter = create<CounterState>({ count: 0 });
export const count = counter.select((state) => state.count);
```

```svelte lineNumbers
<script lang="ts">
  import { counter, count } from './counter';

  const increment = () => {
    counter.update((state) => ({ ...state, count: state.count + 1 }));
  };
</script>

<button on:click={increment}>{$count}</button>
```

## Return shape

The Svelte adapter returns Svelte store objects:

- state mode: `Writable<T>` with `set`, `update`, plus `setState`, `select`, `writeOnly`, `readOnly`
- reducer mode: readable store + `dispatch`, `select`, `writeOnly`, `readOnly`

Use `set()` or `update()` for standard Svelte writes, `setState()` when you want the same writer name used by other adapters, and `select()` to create derived readable stores for focused subscriptions.

## Lifecycle rule

Svelte manages subscription cleanup through the store contract. Components using `$store` syntax subscribe on mount and unsubscribe on destroy.
