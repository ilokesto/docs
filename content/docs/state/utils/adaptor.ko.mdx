# `adaptor`

`adaptor`는 Immer draft recipe를 객체 상태용 순수 updater로 바꿉니다. 변경은 `draft`에 작성하고, 반환된 함수가 다음 불변 상태를 만듭니다.

```ts lineNumbers
import { adaptor } from '@ilokesto/state/utils';

type State = { user: { profile: { name: string } } };

const renameProfile = adaptor<State>((draft) => {
  draft.user.profile.name = 'New Name';
});

useStore.writeOnly()(renameProfile);
```

## 동작

- `adaptor`는 객체 상태 형태를 받습니다.
- recipe는 Immer draft를 받으므로, recipe 안에서는 중첩 값을 직접 대입할 수 있습니다.
- 반환된 updater는 `writeOnly()`에 전달할 수 있는 순수 함수입니다.
- `immer`는 선택적 peer dependency입니다. `adaptor`를 쓰기 전에 설치하세요.

## 설치

```package-install
immer
```
