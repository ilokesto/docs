# 로거

`logger` 미들웨어는 각 상태 업데이트를 브라우저 콘솔에 출력합니다. 각 로그에는 이전 상태, 다음 상태, 업데이트에 액션 이름이 있을 때 그 이름이 포함됩니다.

```ts lineNumbers
import { logger } from '@ilokesto/state/middleware';

const store = logger({ collapsed: true })({ count: 0 });
```

## 옵션

- `collapsed`: (기본값: `false`) 각 콘솔 그룹을 접힌 상태로 시작합니다.
- `diff`: (기본값: `false`) 이전 상태와 다음 상태 사이의 깊은 비교(deep diff)를 추가합니다.
- `timestamp`: (기본값: `true`) 로그 헤더에 타임스탬프를 추가합니다.

## 운영 환경 동작

운영(production) 환경에서 `logger`는 스스로 비활성화됩니다. 콘솔 출력에 작업을 쓰거나 콘솔에 상태 세부 정보가 드러나지 않도록 로깅 없이 원래 스토어를 반환합니다.
