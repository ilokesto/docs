# Tutorial: build a small cart store

This tutorial creates a tiny cart store with plain TypeScript. It focuses on the core `Store` loop: create state, read state, subscribe to changes, update state, and clean up the subscription.

## 1. Create the store

Define the state shape first, then pass the initial state to `new Store()`.

```ts lineNumbers
import { Store } from "@ilokesto/store";

type CartItem = {
  id: string;
  title: string;
  quantity: number;
};

type CartState = {
  items: CartItem[];
};

const cartStore = new Store<CartState>({
  items: [],
});
```

## 2. Read the current state

Use `getState()` whenever you need the latest value.

```ts lineNumbers
const currentCart = cartStore.getState();

console.log(currentCart.items);
```

## 3. Subscribe to changes

`subscribe()` receives a listener and returns an unsubscribe function. The listener does not receive the state directly, so read the latest value with `getState()` inside the listener.

```ts lineNumbers
const unsubscribe = cartStore.subscribe(() => {
  console.table(cartStore.getState().items);
});
```

## 4. Update with `setState`

`setState()` replaces the stored value. For object state, return a new object instead of mutating the previous one.

```ts lineNumbers
function addItem(item: CartItem): void {
  cartStore.setState((prev) => ({
    items: [...prev.items, item],
  }));
}

function increaseQuantity(id: string): void {
  cartStore.setState((prev) => ({
    items: prev.items.map((item) =>
      item.id === id ? { ...item, quantity: item.quantity + 1 } : item
    ),
  }));
}

function clearCart(): void {
  cartStore.setState({ items: [] });
}
```

## 5. Put it together

```ts lineNumbers
addItem({ id: "keyboard", title: "Keyboard", quantity: 1 });
increaseQuantity("keyboard");
clearCart();

unsubscribe();
```

After `unsubscribe()` runs, the listener is removed and no longer reacts to later `setState()` calls.

## Key takeaways

- `Store<T>` keeps one typed state value.
- `setState()` accepts either the next value or a function that receives the previous value.
- Subscribers run only after the state is replaced with a different value.
- Always call the unsubscribe function when the listener is no longer needed.
