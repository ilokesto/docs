# Utils

`@ilokesto/state/utils` exports `pipe` and `adaptor`.

## `pipe`

`pipe(initialState, ...middlewares)` creates a new `Store<T>` and applies middleware functions from left to right.

```ts lineNumbers
import { logger, persist } from '@ilokesto/state/middleware';
import { pipe } from '@ilokesto/state/utils';

const store = pipe(
  { count: 0 },
  logger({ collapsed: true }),
  persist({ local: 'counter' }),
);
```

Caveat: `pipe` creates a new `Store`. If you already own a `Store<T>`, apply middleware directly or pass that store to middleware helpers.

## `adaptor`

`adaptor(fn)` wraps Immer `produce` for object state updates. It requires `immer` as an optional peer dependency.

```ts lineNumbers
import { adaptor } from '@ilokesto/state/utils';

setState(adaptor((draft) => {
  draft.count += 1;
}));
```

Caveat: `adaptor` is constrained to object state. Use direct next values or updater functions for primitive state.
