# Solid

Solid 어댑터 API는 `@ilokesto/state/solid`에서 가져옵니다.

```tsx lineNumbers
import { create } from '@ilokesto/state/solid';

type CounterState = { count: number };

const useCounter = create<CounterState>({ count: 0 });

function Counter() {
  const { state, setState } = useCounter((current) => current.count);

  return (
    <button onClick={() => setState((prev) => ({ ...prev, count: prev.count + 1 }))}>
      {state()}
    </button>
  );
}
```

## 반환 형태

Solid 어댑터는 accessor를 만드는 함수를 반환합니다.

- state mode: `{ state: Accessor<S>, setState }`
- reducer mode: `{ state: Accessor<S>, dispatch }`

## Lifecycle 규칙

`create()`가 반환한 함수는 컴포넌트나 `createRoot()` 같은 reactive owner 안에서 호출하세요. Solid scope 밖에서 동기적으로 읽을 때는 `readOnly()`를 사용하세요.
