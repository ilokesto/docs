# Vue

Import Vue adapter APIs from `@ilokesto/state/vue`.

```ts lineNumbers
import { create } from '@ilokesto/state/vue';

type CounterState = { count: number };

const useCounter = create<CounterState>({ count: 0 });

export function useCounterState() {
  const { state, setState } = useCounter((current) => current.count);

  return {
    count: state,
    increment: () => setState((prev) => ({ ...prev, count: prev.count + 1 })),
  };
}
```

## Return shape

The Vue adapter returns a composable. Calling it returns:

- state mode: `{ state: ComputedRef<S>, setState }`
- reducer mode: `{ state: ComputedRef<S>, dispatch }`

The selected value is a `ComputedRef`, so templates unwrap it naturally.

## Lifecycle rule

The returned composable must run inside `setup()` or an active `effectScope()`. Outside Vue lifecycle, use `readOnly()` for synchronous reads or `writeOnly()` for writes.
