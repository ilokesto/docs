# `pipe`

`pipe` builds a `Store` from plain initial state, applies middleware in order, and returns the initialized store.

```ts lineNumbers
import { create } from '@ilokesto/state';
import { pipe } from '@ilokesto/state/utils';
import { logger, devtools } from '@ilokesto/state/middleware';

const store = pipe(
  { count: 0 },
  logger(),
  devtools('MyStore')
);

const useStore = create(store);
```

## How it works

- It starts from plain initial state.
- It creates a vanilla `Store`.
- It applies middleware from left to right.
- It returns the resulting `Store` so you can pass it to `create(store)`.

## When to use it

Reach for `pipe` when a store needs more than one middleware and nested calls would hide the order.
