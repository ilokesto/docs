# Store

`@ilokesto/store`는 하나의 TypeScript 상태 값을 저장하고, `setState`로 값을 교체하며, 교체가 성공하면 구독자에게 알립니다.

이 계약은 프레임워크에 묶이지 않으므로 React, Vue, Svelte, Angular, 그 밖의 런타임은 핵심 상태 계층을 소유하지 않고 어댑터를 통해 연결할 수 있습니다.

## 패키지 경계

이 패키지는 `@ilokesto/store`에서 `Store<T>`를 내보냅니다.

다루는 범위:

- 하나의 저장된 상태 값,
- 현재 상태와 초기 상태 읽기,
- 값 또는 업데이트 함수로 실행하는 교체 업데이트,
- 성공한 상태 변경 구독,
- 현재 공개 메서드 이름을 쓰는 소스 기반 미들웨어.

다루지 않는 범위:

- 프레임워크 hook,
- selector 또는 reducer,
- persistence 또는 data fetching,
- devtools,
- 비동기 스케줄링.


## 작은 예제

```ts lineNumbers
import { Store } from "@ilokesto/store";

const counterStore = new Store({ count: 0 });

const unsubscribe = counterStore.subscribe(() => {
  console.log(counterStore.getState());
});

counterStore.setState((prev) => ({ ...prev, count: prev.count + 1 }));

unsubscribe();
```
