# 업데이트 시맨틱 이동됨

이 페이지는 더 이상 최신 문서가 아니며, 오래된 링크를 위해 남겨 둔 deprecated legacy route입니다.

자세한 업데이트 동작은 이제 [고급 시맨틱](./advanced-semantics)으로 이동했습니다.

교체 업데이트, `Object.is` 베일아웃, 중첩 객체 시맨틱, 알림 순서는 [고급 시맨틱](./advanced-semantics)을 참고하세요.
