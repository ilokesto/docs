# @ilokesto/state

`@ilokesto/state`는 외부 스토어 상태를 React 훅으로 바꿉니다. 스토어는 React 바깥에 남고, 읽기와 구독은 `useSyncExternalStore`를 통해 흐릅니다.

## 이 패키지가 제공하는 것

- 상태 객체나 vanilla store를 받는 하나의 `create()` 진입점
- 서로 다른 갱신 방식에 맞는 상태 모드와 리듀서 모드
- 컴포넌트 읽기 범위를 좁히는 셀렉터 구독
- 컴포넌트 밖 작업을 위한 `writeOnly()` 같은 명령형 접근자
- 로깅, 영속화, 검증, 디버깅을 위한 스토어 미들웨어

## 의도적으로 제공하지 않는 것

- Provider 중심 앱 구조
- Zustand 스타일 initializer
- 셀렉터용 custom equality API
- 훅 뒤의 실제 스토어를 감추는 추상화

## 설치

```package-install
@ilokesto/state
```

## 훑어보기

```tsx lineNumbers
import { create } from '@ilokesto/state';

const useCounter = create({ count: 0 });

function Counter() {
  const [count, setState] = useCounter((state) => state.count);

  return (
    <button onClick={() => setState((prev) => ({ ...prev, count: prev.count + 1 }))}>
      {count}
    </button>
  );
}
```

모양은 작습니다.

- `create()`가 외부 상태를 훅으로 바꾸고,
- selector가 컴포넌트가 읽을 범위를 정하고,
- writer는 여전히 전체 store state를 갱신합니다.
