# Plain state 가이드

다음 상태를 직접 설명하기 쉬우면 plain state를 사용하세요.

```ts lineNumbers
import { create } from '@ilokesto/state/vue';

const useFilter = create({ query: '', page: 1 });

export function useSearchBox() {
  const { state, setState } = useFilter((state) => state.query);
  const setQuery = (query: string) => setState((prev) => ({ ...prev, query, page: 1 }));
  return { query: state, setQuery };
}
```

form, toggle, filter, 작은 shared state에는 plain state가 잘 맞습니다. `@ilokesto/store`는 `setState`로 새 값을 받은 뒤 알리므로 immutable replacement를 선호하세요.

Caveat: adapter마다 반환 형태가 다릅니다. destructuring하기 전에 사용하는 Integration page를 확인하세요.
