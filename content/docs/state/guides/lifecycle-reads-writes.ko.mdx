# Lifecycle reads and writes

router guard, network callback, test가 component subscription 없이 current state를 필요로 할 때가 있습니다.

```ts lineNumbers
const readAuth = useAuth.readOnly;
const writeAuth = useAuth.writeOnly();

export function requireLogin() {
  if (!readAuth((state) => state.user)) throw new Error('Login required');
}

export function logout() {
  writeAuth({ user: null });
}
```

reactive adapter call은 프레임워크가 cleanup할 수 있는 곳에서만 사용하세요. 그 밖에서는 `readOnly`와 `writeOnly`를 사용하세요.

Caveat: `readOnly`는 snapshot read입니다. subscribe하지 않으며 state가 바뀌어도 코드를 다시 실행하지 않습니다.
