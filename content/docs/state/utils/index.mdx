# Utilities

`@ilokesto/state/utils` contains small helpers for cases where the base `create()` API is already right, but the setup code needs a clearer shape.

The two helpers solve different problems:

- `pipe` composes store creation with middleware. Start with plain initial state, apply middleware from left to right, then pass the returned `Store` to `create(store)`.
- `adaptor` wraps Immer's `produce()`. Write a draft-style object update, then pass the returned updater to `writeOnly()` or another store write path.

## Choosing between them

Use `pipe` when store setup is the noisy part.

Use `adaptor` when object update syntax is the noisy part.

Stay with plain `create()` when you do not need middleware composition or draft-style object updates.

## How they differ

`pipe` works before React binding. It builds the store instance that `create(store)` will bind.

`adaptor` works during writes. It turns an Immer draft recipe into a pure updater function for object state.

- [`create`](../create): Main entry point for React integration.
- [`middleware`](../middleware): Built-in middleware for common tasks.
