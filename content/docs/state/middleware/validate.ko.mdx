# 검증

`validate` 미들웨어는 Standard Schema v1 유효성 검사기를 받아, 스토어가 커밋하기 전에 모든 다음 상태를 검사합니다. 검증이 실패하면 업데이트를 멈추고 현재 상태를 그대로 둡니다.

```ts lineNumbers
import { validate } from '@ilokesto/state/middleware';
import { z } from 'zod'; // Zod는 Standard Schema v1을 지원합니다

const schema = z.object({ count: z.number().min(0) });
const store = validate(schema)({ count: 0 });
```

## 동작

- **Standard Schema v1**: Zod, Valibot, ArkType처럼 Standard Schema v1 계약을 제공하는 스키마 라이브러리와 함께 동작합니다.
- **차단형 검증**: 유효하지 않은 결과를 로그로 남긴 뒤, 업데이트가 스토어에 도달하기 전에 중단합니다.
- **커밋된 상태 유지**: 실패한 업데이트는 이전 상태를 바꾸지 않습니다.

## 제한

- **동기 전용**: 비동기 스키마 유효성 검사는 거부됩니다. 유효성 검사기는 동기 결과를 반환해야 합니다.
- **커밋 비용**: 검증은 각 커밋 전에 실행되므로, 비용이 큰 스키마 검사는 UI 반응성에 영향을 줄 수 있습니다.
