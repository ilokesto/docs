# Store

`@ilokesto/store`는 Store 문서의 중심에 있는 작은 상태 컨테이너입니다. 하나의 상태 값을 보관하고, `setState`로 그 값을 교체하며, 교체가 성공하면 리스너에게 알립니다.

React, Vue, Svelte, Angular 또는 다른 프레임워크에 의존하지 않는 plain TypeScript 상태 계약이 필요할 때 이 패키지를 사용하세요.

## 패키지 경계

이 패키지는 `@ilokesto/store`에서 `Store<T>`를 내보냅니다.

다루는 범위는 다음과 같습니다.

- 하나의 상태 값 저장,
- 현재 상태와 초기 상태 읽기,
- 값 또는 업데이트 함수로 상태 교체,
- 성공한 상태 변경 구독,
- 현재 공개 메서드 이름을 쓰는 소스 기반 미들웨어 추가.

프레임워크 hook, selector, reducer, persistence, data fetching, devtools, 비동기 스케줄링은 제공하지 않습니다. 그런 기능은 어댑터나 더 높은 수준의 패키지가 맡습니다.

## 설치

```package-install
@ilokesto/store
```

## 작은 예제

```ts
import { Store } from "@ilokesto/store";

const counterStore = new Store({ count: 0 });

const unsubscribe = counterStore.subscribe(() => {
  console.log(counterStore.getState());
});

counterStore.setState((prev) => ({ ...prev, count: prev.count + 1 }));

unsubscribe();
```

이 예제는 의도적으로 단순합니다. 스토어 하나를 만들고, 스냅샷을 읽고, 상태를 교체하고, 변경을 듣고, 더 필요 없을 때 리스너를 제거하는 패키지의 전체 모양을 보여줍니다.
