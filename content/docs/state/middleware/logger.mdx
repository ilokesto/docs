# Logger

The `logger` middleware prints each state update to the browser console. Each log includes the previous state, the next state, and the action name when the update has one.

```ts lineNumbers
import { logger } from '@ilokesto/state/middleware';

const store = logger({ collapsed: true })({ count: 0 });
```

## Options

- `collapsed`: (default: `false`) Starts each console group collapsed.
- `diff`: (default: `false`) Adds a deep diff between the previous and next state.
- `timestamp`: (default: `true`) Adds a timestamp to the log header.

## Production Behavior

In production mode, `logger` disables itself. It returns the original store without logging so production bundles do not spend work on console output or expose state details there.
