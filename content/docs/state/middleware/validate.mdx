# Validate

The `validate` middleware accepts a Standard Schema v1 validator and checks every next state before the store commits it. When validation fails, the update stops and the current state stays unchanged.

```ts lineNumbers
import { validate } from '@ilokesto/state/middleware';
import { z } from 'zod'; // Zod supports Standard Schema v1

const schema = z.object({ count: z.number().min(0) });
const store = validate(schema)({ count: 0 });
```

## Behavior

- **Standard Schema v1**: Works with schema libraries that expose the Standard Schema v1 contract, including Zod, Valibot, and ArkType.
- **Blocking validation**: Invalid results are logged, then the update is aborted before it reaches the store.
- **Committed state only**: A failed update does not replace the previous state.

## Limits

- **Synchronous only**: Async schema validation is rejected. The validator must return a synchronous result.
- **Commit cost**: Validation runs before each commit, so expensive schema checks can affect UI responsiveness.
