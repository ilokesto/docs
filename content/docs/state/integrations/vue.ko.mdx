# Vue

Vue adapter는 root package가 아니라 `@ilokesto/state/vue`에서 import하세요.

```ts lineNumbers
import { create } from '@ilokesto/state/vue';

const useCounter = create({ count: 0 });

export default {
  setup() {
    const { state, setState } = useCounter((state) => state.count);
    const inc = () => setState((prev) => ({ count: prev.count + 1 }));
    return { count: state, inc };
  },
};
```

## Return shape

plain state는 `{ state: ComputedRef<S>, setState }`를 반환합니다. reducer state는 `{ state: ComputedRef<S>, dispatch }`를 반환합니다.

## Reducer state

같은 `create(reduce, initialState)` overload는 selector를 유지하면서 writer를 `setState`에서 `dispatch`로 바꿉니다.

## Outside lifecycle

subscribe하지 않아야 하는 event bus, service function, test, synchronous snapshot read에는 `readOnly()`와 `writeOnly()`를 사용하세요.

## Caveat

reactive call은 `setup` 또는 active `effectScope`가 필요합니다. 그 밖에서는 `readOnly()`를 사용하세요.
